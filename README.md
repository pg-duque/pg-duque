## 🚀 Proyectos destacados

### 🖥️ [Proyecto Final DAM | Frontend HTML, CSS y JavaScript](https://github.com/pg-duque/Proyecto-Final-1-DAM---Frontend/tree/master)

Interfaz web para visualizar y gestionar una galería de clases de personajes. Desarrollada con **HTML, CSS, JavaScript y Bootstrap 5**, conectada a una **API REST local**.

El proyecto trabaja la manipulación dinámica del DOM, el renderizado de tarjetas, la organización visual de la información y la conexión entre una interfaz frontend y un backend independiente.

**Tecnologías utilizadas:** HTML5, CSS3, JavaScript, Bootstrap 5, API REST.

---

### ☕ [Proyecto Final DAM | Backend Java, Spring Boot y PostgreSQL](https://github.com/pg-duque/Proyecto-Final-1-DAM---Backend)

API REST desarrollada con **Java y Spring Boot** para gestionar los datos de la galería. Incluye persistencia con **PostgreSQL**, uso de **JPA/Hibernate** y endpoints preparados para conectar con el frontend del proyecto.

Este repositorio representa la parte backend del proyecto final, aplicando conceptos de arquitectura por capas, gestión de entidades, repositorios, servicios y controladores.

**Tecnologías utilizadas:** Java, Spring Boot, PostgreSQL, JPA/Hibernate, Maven, API REST.

---

### 🐍 [LeakQ | Automatización de escritorio con Python y OpenCV](https://github.com/pg-duque/leakq)

Proyecto personal de automatización local desarrollado en **Python**, centrado en captura de pantalla, detección visual mediante **OpenCV** y ejecución controlada de acciones con **PyAutoGUI**.

Incluye configuración externa, logs, control mediante hotkeys, icono en bandeja del sistema y empaquetado como aplicación ejecutable con **PyInstaller**.

**Tecnologías utilizadas:** Python, OpenCV, PyAutoGUI, PyInstaller, JSON, automatización de escritorio.
