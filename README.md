## 🚀 Proyectos destacados

### ☕ Galería D&D — Proyecto final de 1.º de DAM

Aplicación web para visualizar y gestionar una galería de clases de personajes de Dungeons & Dragons, con **frontend y backend separados**.

- **Backend:** API REST con Java y Spring Boot, persistencia en PostgreSQL y acceso a datos mediante JPA / Hibernate.
- **Frontend:** interfaz con HTML, CSS, JavaScript y Bootstrap 5 que consume la API mediante Fetch.
- **Funcionalidades:** consulta, creación, edición y eliminación de clases de personajes, renderizado dinámico de tarjetas y visualización de detalles.

Este proyecto me permitió trabajar la conexión entre interfaz, lógica de aplicación y base de datos.

**Repositorios:** [Backend](https://github.com/pg-duque/Proyecto-Final-1-DAM---Backend) · [Frontend](https://github.com/pg-duque/Proyecto-Final-1-DAM---Frontend)

### 🐍 LeakQ — Automatización de escritorio con Python

Herramienta para Windows que detecta en pantalla el botón de confirmación de partida de Dota 2 y automatiza su aceptación.

Utiliza **OpenCV para comparar imágenes con una plantilla** y **PyAutoGUI para ejecutar la acción**. Incluye:

- Captura de una región configurable de la pantalla.
- Confirmación de la detección durante varios fotogramas.
- Control de clics repetidos mediante tiempos de espera.
- Configuración externa, logs, atajos de teclado e icono en la bandeja del sistema.
- Empaquetado como ejecutable con PyInstaller.

Proyecto personal desarrollado con asistencia de IA, centrado en explorar la automatización de escritorio y la detección visual.

**Repositorio:** [LeakQ](https://github.com/pg-duque/leakq)
